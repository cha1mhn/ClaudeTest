# ClaudeTest
Claude Testing Environment - Connected to Claude Opus

## Projects

### [RevOps Forecasting Tool](./revops-forecasting-tool/)
A full-stack revenue operations forecasting tool with HubSpot CRM integration.
Embeds directly into HubSpot as a CRM Card. Supports weighted pipeline, forecast
categories, historical win-rate, and trend-based forecasting methods.

### [GTM Pipeline Hygiene Auditor](./pipeline-hygiene-auditor/)
A data quality auditor for go-to-market teams integrating HubSpot CRM and Clay.
Grades pipeline health (A-F), flags stale deals, missing fields, enrichment gaps,
and pipeline bottlenecks. Embeds into HubSpot as a CRM Card with actionable
RevOps recommendations.
