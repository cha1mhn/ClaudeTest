# Mood Tracker

An interactive mood tracking app built with vanilla HTML, CSS, and JavaScript. No dependencies required.

## Features

- **Record moods** with 5 levels (Awful to Great) plus optional activities and notes
- **History view** with time-based filtering (Today, This Week, This Month)
- **Insights dashboard** with average score, streak tracking, mood-over-time chart, and distribution bars
- **Persistent storage** via localStorage - your data stays in your browser
- **Responsive design** works on desktop and mobile
- **Dark theme** with gradient UI

## Usage

Open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8080
# then visit http://localhost:8080
```
